# ☕ Avaliação Prática I — Programação Orientada a Objetos (POO)

Este repositório contém a resolução prática da **Primeira Avaliação** da disciplina de **Programação Orientada a Objetos**, ministrada no curso de **Ciência da Computação**.

O objetivo desta avaliação foi consolidar os fundamentos da linguagem Java e demonstrar a capacidade de abstração, estruturação e resolução de problemas utilizando o paradigma orientado a objetos.

---

## 📌 Escopo e Objetivos da Avaliação

A prova consistiu no desenvolvimento de classes e modelos de domínio para solucionar cenários práticos, priorizando clareza arquitetural, legibilidade e manutenibilidade do código.

Os seguintes princípios fundamentais foram aplicados:
* **Abstração:** Identificação clara das entidades, seus atributos essenciais e métodos relevantes para o domínio do problema.
* **Encapsulamento:** Proteção do estado interno dos objetos através do uso rigoroso de modificadores de acesso (`private`, `protected`, `public`), além de métodos de leitura/escrita (*getters* e *setters*) com validações pertinentes.
* **Construtores:** Inicialização consistente e segura dos objetos, garantindo estados válidos desde a instanciação.
* **Lógica e Controle de Fluxo:** Implementação eficiente de métodos de negócio utilizando estruturas condicionais, laços de repetição e tipos de dados primitivos/referenciais do Java.
